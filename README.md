# DipaolaFederico/scoop-bucket

Scoop bucket for [kmd](https://github.com/DipaolaFederico/kmd), a fast Markdown previewer for the terminal.

```powershell
scoop bucket add dipaolafederico https://github.com/DipaolaFederico/scoop-bucket
scoop install kmd
```

`bucket/kmd.json` is updated by the kmd release workflow on every release; do not edit it by hand.
Issues: <https://github.com/DipaolaFederico/kmd/issues>.
